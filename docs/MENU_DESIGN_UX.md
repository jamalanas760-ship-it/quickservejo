# QuickServe Menu Design Studio UX

The Menu Design Studio is mobile-first and uses a single responsive creative canvas.

- Desktop: three-column creation, canvas, and editing workspace.
- Tablet: focused canvas with collapsible controls.
- iOS/Android: Create, Preview, Edit, and Layers as bottom navigation states.
- The menu canvas uses a normal 4:3 design surface instead of a tall phone mockup.
- Text layers never intentionally collapse into one character per line when a narrow generated width is returned.
- Safe-area spacing is used for mobile navigation.
- Reduced-motion preferences are respected.
